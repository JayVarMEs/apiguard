## Download summary

- Seven full papers were downloaded as PDFs and validated by opening them, checking their page counts, and rendering their first pages.
- References [7], [8], and [10] are software repositories, so their current README files were saved instead of paper PDFs.
- Reference [4] is a real conference paper, but its full PDF is not freely downloadable from the publisher. The official conference page and the associated tool README were saved.
